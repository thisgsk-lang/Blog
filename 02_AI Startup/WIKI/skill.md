# Marp 마크다운 작성 가이드

Marp로 프리뷰할 때 깨지지 않는 마크다운 작성 규칙

---

## 1. 프론트매터 (Front Matter)

필수 설정:

```markdown
---
marp: true
theme: default
paginate: true
---
```

- `marp: true` - Marp 프리젠테이션 활성화
- `theme: default` - 기본 테마 (또는 gaia, uncover 등)
- `paginate: true` - 페이지 번호 표시 여부

---

## 2. 슬라이드 구분

슬라이드 분리는 `---`를 **독립 라인**으로 사용:

```markdown
# 첫 번째 슬라이드

내용...

---

# 두 번째 슬라이드

내용...
```

⚠️ `---`는 반드시 위아래 공백 라인과 함께 사용

---

## 3. 헤더 계층 구조

- `#` - 슬라이드 제목 (레벨 1)
- `##` - 섹션 제목 (레벨 2)
- `###` - 소제목 (레벨 3)

```markdown
# 메인 제목

## 부제목

내용...
```

---

## 4. 이미지 경로

상대 경로를 **명시적으로** 지정:

```markdown
![Alt text](./images/example.png)
![Alt text](../assets/image.jpg)
```

- `./` - 현재 폴더
- `../` - 상위 폴더
- 절대 경로 지양

---

## 5. 리스트 형식

들여쓰기 일관성 유지:

```markdown
- 항목 1
- 항목 2
  - 중첩 항목 2-1
  - 중첩 항목 2-2
- 항목 3
```

⚠️ 탭과 스페이스 혼합 금지 (2-4 스페이스 사용)

---

## 6. 코드 블록

언어 명시:

````markdown
```

```javascript

```

```
````

---

## 7. 테이블

파이프 정렬 확인:

```markdown
| 헤더 1 | 헤더 2 | 헤더 3 |
|--------|--------|--------|
| 값 1   | 값 2   | 값 3   |
| 값 4   | 값 5   | 값 6   |
```

---

## 8. 링크

마크다운 형식 사용:

```markdown
[텍스트](https://example.com)
[상대 링크](./other-file.md)
[파일 링크](#섹션-제목)
```

⚠️ HTML `<a>` 태그 지양

---

## 9. 특수 문자 이스케이프

필요시 백슬래시로 이스케이프:

```markdown
\* 별표
\# 해시
\| 파이프
\` 백틱
```

---

## 10. 주의사항

❌ **피해야 할 것:**
- 혼합된 탭/스페이스
- 마크다운 내 HTML 태그 과다 사용
- 상대 경로 불명확
- `---` 라인 들여쓰기
- 빈 슬라이드 (내용 없음)

✅ **권장:**
- 명확한 구조와 계층
- 일관된 들여쓰기 (2-4 스페이스)
- 명시적 경로 지정
- 정기적인 프리뷰 확인

---

## 11. 프리뷰 확인

파일 작성 후:

1. VS Code에서 Marp 확장 설치
2. 마크다운 파일 우클릭 → "Marp: Open Preview"
3. 레이아웃 확인 및 수정
