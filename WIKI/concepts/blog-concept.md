# 블로그란 무엇인가?

## 정의

블로그 = 콘텐츠 + 디자인 + 기술 + 기획

세 가지가 모두 필요하다.

---

## 블로그의 3가지 층

### 1층: 기획 (가장 중요)
- **누구를 위한가?**
- **왜 만드는가?**
- **어떤 콘텐츠를 만들 것인가?**
- **어떻게 성공을 정의할 것인가?**

기획이 약하면 → 아무리 멋진 디자인도 죽는다.

### 2층: 콘텐츠
- 글, 이미지, 영상
- W06에서 만든 Wiki/Raw 자료들
- 구체적이고 도움이 되는 내용

### 3층: 디자인 & 기술
- 보기 좋은 UI (W09 Claude Design)
- 동작하는 기술 (GitHub Pages, Claude Code)

---

## 블로그 만들기 흐름

```
기획 4질문 (15분)
    ↓
콘텐츠 준비 (W06 활용)
    ↓
디자인 (W09 활용)
    ↓
코드 조립 (Claude Code)
    ↓
GitHub Pages 배포 (W07)
    ↓
세상에 공개
```

---

## 블로그가 죽는 이유

### "껍데기만 있는 블로그"
- 디자인은 예쁘지만 콘텐츠가 없음
- 한 달 후: 포기

### "동기 없는 블로그"
- 왜 만드는지 모름
- 시간 들이면 1년 후 끝남

### "타겟 없는 블로그"
- "모두를 위해" 만듦
- 결국 아무도 아님

---

## 성공하는 블로그의 공통점

1. **명확한 타겟**: 구체적인 사람이 떠오름
2. **강한 동기**: 나에게 솔직한 이유
3. **좋은 콘텐츠**: 사람들이 찾는 정보
4. **나만의 목소리**: 유일한 관점

**필수**: 온라인에서 만나지 않으면 안 되는 사람들의 마음을 사로잡아야 성공한다.
