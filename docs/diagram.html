📌 데이터 흐름:
1️⃣ 관리자가 글을 작성하면 localStorage에 JSON 형식으로 저장됩니다.
2️⃣ 고객용 블로그는 localStorage에서 공개된 글만 읽어서 독자에게 표시합니다.
3️⃣ 이 모든 과정이 클라이언트 사이드에서 처리됩니다.
⚙️ CRUD 작업 흐름
Create, Read, Update, Delete 작업의 상세 흐름
작업 설명 단계
📝 CREATE 새로운 글 작성 1. 제목, 내용 입력 → 2. 저장 → 3. localStorage 저장
📖 READ 글 목록 조회 1. 콘텐츠 관리 탭 → 2. localStorage 조회 → 3. 테이블 표시
✏️ UPDATE 글 수정 1. 수정 버튼 → 2. 내용 로드 → 3. 수정 → 4. 저장
🗑️ DELETE 글 삭제 1. 삭제 버튼 → 2. 확인 → 3. localStorage에서 제거
