블로그를 한 시간에 만들기

작성일: 2026-05-12

들어가며

"블로그를 만들고 싶은데 복잡할 것 같다"

이 글은 HTML 모르는 사람도 90분 안에 웹사이트를 만드는 방법입니다.

90분 로드맵

시간 할 일 결과
0~15분 기획 4질문 작성 방향 명확화
15~30분 콘텐츠 3개 작성 글 완성
30~60분 GitHub 저장소 만들기 코드 준비
60~90분 GitHub Pages 배포 웹사이트 라이브

Step 1: 기획 4질문 (15분)

질문

  1. 누구를 위한 거야? (한 줄)
  2. 왜 만들어? (한 줄)
  3. 첫 콘텐츠 3개 제목 (3개)
  4. 무엇이 성공인가? (한 줄)

예시

1. 디자이너로 시작하는 30대를 위해
2. 내가 겪은 시행착오를 정리해주려고
3. "AI 도구 첫주", "GitHub 협업", "블로그 만들기"
4. "이 블로그로 나를 찾았어"라는 말 듣기

Step 2: 콘텐츠 작성 (15분)

목표

  • 3개 글 완성 (각 5분)
  • 완벽할 필요 없음
  • 시작이 중요

구조 (각 글당)

  • 들어가며 (1문)
  • 목차 3~5개
  • 마치며 (다음 행동)

Step 3: GitHub 저장소 (15분)

순서

  1. GitHub.com 회원가입
  2. "Obsidian" 이름으로 저장소 생성
  3. README.md 작성
  4. 파일 올리기 (git push)

코드 (그냥 복사-붙여넣기)

git init
git add .
git commit -m "Initial commit"
git push -u origin main

Step 4: GitHub Pages 배포 (15분)

준비물

  • docs/ 폴더 안 HTML 파일들

활성화

  1. Settings → Pages
  2. Source: main / /docs 선택
  3. Save

결과

30초 후 라이브 됨!

꿀팁 5가지

1. 경로는 상대 경로로

❌ <link href="/style.css">
✅ <link href="../style.css">

2. 다중 계정이면 인증 확인

gh auth status
gh auth login

3. README는 필수

저장소를 보는 첫인상!

4. 작게 시작, 크게 키우기

  • Week 1: 3개 글
  • Week 2: 5개 글
  • Week 3: 카테고리 추가

5. 블로그는 "과정"이다

완벽함보다 계속 쓰는 것이 중요!

마치며

"완벽한 블로그를 나중에 만드는 것보다, 지금 불완전한 블로그를 만드는 게 낫다"

당신의 첫 블로그는 완벽하지 않을 겁니다.

그래도 좋습니다.

시작했으니까요.
