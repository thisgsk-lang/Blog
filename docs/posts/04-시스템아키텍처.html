CRUD 작업 흐름

✏️ Create - 새 글 작성

"새 글 작성" 탭에서 제목, 내용(마크다운), 태그를 입력하고 "저장" 버튼을 클릭하면 localStorage에 저장됩니다.

📖 Read - 글 목록 조회

"콘텐츠 관리" 탭에서 저장된 모든 글이 테이블로 표시됩니다. 제목, 상태, 작성일, 수정일, 작업 버튼이 각 행에 보입니다.

✏️ Update - 글 수정 및 상태 변경

수정: "수정" 버튼을 클릭하면 글의 내용이 에디터에 로드되고, 수정 후 저장하면 기존 글이 업데이트됩니다.

상태 토글: "공개중" 또는 "발행" 버튼을 클릭하여 공개/초안 상태를 즉시 변경할 수 있습니다.

🗑️ Delete - 글 삭제

"삭제" 버튼을 클릭하면 확인 대화가 나타나고, 확인하면 해당 글이 localStorage에서 제거됩니다.

데이터 저장 구조

모든 글은 JSON 형식으로 localStorage에 저장됩니다:


{
  "id": 1778586591944,
  "title": "AI 도구로 시작하는 첫주",
  "content": "마크다운 형식의 내용...",
  "tags": ["AI", "도구", "블로그"],

  "createdAt": "2026-05-12T11:49:51.944Z",
  "updatedAt": "2026-05-12T11:49:51.944Z"
}
